## Обзор

Симуляция моделирует маркет-мейкера, который устанавливает цены покупки (bid) и продажи (ask) для финансового инструмента и взаимодействует с различными типами трейдеров:

1. **Информированные трейдеры**, обладающие частной информацией о будущей стоимости актива.
2. **Ликвидные трейдеры**, совершающие сделки на основе экзогенных потребностей, а не информации.

Маркет-мейкер использует различные стратегии (пассивную, агрессивную и адаптивную) для максимизации прибыли при управлении рисками.

## Основные Возможности

- Три стратегии маркет-мейкера:
  - **Пассивная**: Узкий спред для максимизации объема торгов.
  - **Агрессивная**: Широкий спред для максимизации прибыли на одну сделку.
  - **Адаптивная**: Динамическая корректировка спреда в зависимости от рыночных условий.
- Моделирование взаимодействия с использованием теории игр через матрицы выигрышей и равновесие Нэша.
- Автоматическое управление источниками данных (реальные биржевые данные или сгенерированные синтетические данные).
- Система управления рисками с отслеживанием позиций.
- Анализ эффективности стратегий с использованием ключевых метрик.
